WHAT YOU ARE TRANSLATING
VpnHood! is a free, open-source VPN; these strings are its marketing site — nav, page titles, feature cards, pricing, FAQ. Short UI labels, not prose. Two apps share the site: VpnHood! CONNECT (consumer app, built-in free servers) and VpnHood! CLIENT (connects to a server the user hosts with VpnHood! SERVER, administered in VpnHood! MANAGER).
The key names the role: meta_title/meta_description = the page's SEO tags; nav_*/footer_*/oc_* = menu items; row_* = comparison-table rows; *_alt = image alt text; aria_* = read aloud by screen readers; *_title/*_desc = a card's heading and body.
You see one batch at a time, but the same label appears on several pages and must come back identical every time. A bare label with no sentence around it is the name of a thing, not a description of it.

RULES
- "VpnHood" / "VpnHood!" and the product words CLIENT, CONNECT, MANAGER, SERVER, ENGINE never change: always Latin, product words in capitals. Never "VpnHood! مدیریت", "VpnHood! Verwaltung", never وی‌پی‌ان‌هود.
- VPN, API, SDK, open source: whichever form is most natural in the target language.
- Third-party names (GitHub, Google Play, App Store, Windows, Android, Android TV, Linux, iOS, macOS, Cloudflare, LinkedIn, Instagram, X) take the spelling already established in the target language; Latin-script languages keep the original. Whichever form you choose, use it in every file — including inside sentences. Never write a name half in each script ("گitHub"), and never alter one inside a URL or href.
- Write each string in one script. A character from a script that is neither the target language's nor Latin means the output is corrupt — produce it again.
- A version number attached to a Latin product name keeps Western digits ("Android 7.0", "Windows 10") — mixing scripts inside one term is wrong. Every other number follows the language file below, or that language's own norm, used consistently.
- Names are fixed, prose is free. The language file below is written `English = target` in sections: NAMES (identical in every string, including mid-sentence — the things a user clicks or searches for), PROSE (preferred wording in running text: a preference, not a ban), KEYWORDS (meta_title and meta_description only) and RULES. It outranks a nicer-sounding variant, but an ordinary word is not reserved just because a name uses it.
- Capitalization and punctuation are part of a string: one heading style, one punctuation convention (half-width vs full-width), across every file.
- Tone: consumer marketing — friendly, clear, concise. Never translate word for word.
