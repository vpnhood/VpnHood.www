KEYWORDS — meta_title and meta_description keys ONLY (Search Console, Aug–Oct 2026).
Iranians search "وی پی ان" (the top query) and "فیلترشکن" far more than "VPN". In those two
keys render "VPN" / "Free VPN" as فیلترشکن or وی پی ان (spaced exactly so): "Download Free
VPN" = دانلود فیلترشکن رایگان, "free, secure, open-source VPN" = فیلترشکن رایگان، امن و
متن‌باز. Add پرسرعت where the English says fast. People search iOS as آیفون, so here write it آیفون, and
"direct download" as دانلود با لینک مستقیم. In every other key all of these stay as NAMES and RULES say.
RULES
- The famous names in NAMES are written in Persian letters in every string, as Persian writes them, never in Latin.
  Every other name and acronym is Latin in every sentence: VpnHood, iOS, GitHub, Ubuntu, Debian, Cloudflare,
  X, .NET, VPN, IP — never وی‌پی‌ان‌هود، ایکس، گیت‌هاب، دات‌نت، وی‌پی‌ان، آی‌پی.
- Persian digits (۰۱۲۳) everywhere the site already uses them: prices (۷.۹ دلار), plans
  (۱۲ ماهه), discounts (۲۵٪), counts (۵ دستگاه), the copyright year. The ONE exception is a
  version number attached to a name that stays Latin — "iOS 18.0", "Ubuntu 22.04" — which stays
  fully Latin. A name in Persian letters takes Persian digits: ویندوز ۱۰، ویندوز سرور ۲۰۱۶، اندروید ۷.۰.
- Never end a sentence or clause on را by dropping its verb: write the verb out (UDP را امتحان کنید و
  اگر مانعی در کار بود، از TCP استفاده کنید — not ... و وقتی مانعی در کار است، TCP را). In a contrast
  with نه, drop the را: سرور را می‌بینند، نه کاربران — not نه کاربران را.
- Do not add an ezafe ی where normal Persian writes none: شبکه جهانی، مشاهده همه، درباره ما —
  not شبکه‌ی جهانی. When an ی IS part of the word, write it as ZWNJ + ی (درباره‌ی، نسخه‌ی),
  never the hamza form (دربارهٔ، نسخهٔ).
- Do not insert bidi marks (LRM U+200E, RLM U+200F) yourself. The tool adds an LRM after
  "VpnHood!" where it is needed — i.e. when the next word is translated. When the next word
  stays Latin ("VpnHood! CLIENT") the punctuation is already inside a Latin run and no mark
  belongs there. The one exception: put an LRM (U+200E) right before ".NET", or the line shows
  "NET." with its dot moved to the end.
