Brazilian Portuguese glossary.

NAMES — same wording everywhere, including mid-sentence.
These are the ones a translator cannot get right from a single string alone.
Premium = Premium (never translated)
Free (plan name) = Grátis
Kill Switch = Kill Switch
Private DNS = DNS privado
Split DNS = DNS dividido (the app's label)
Split tunneling = Túnel dividido
Go premium = Seja Premium
Premium Pricing = Preços Premium
Features = Recursos
Self-Hosted VPN = VPN auto-hospedada
Download Now = Baixar Agora
(opens in new tab) = (abre em uma nova aba)
Split tunneling by app / by country = Túnel dividido por aplicativos / por países
Frequently Asked Questions = Perguntas frequentes
Learn more = Saiba mais
Free vs Premium = Grátis vs Premium
Cloak Mode = Modo invisível (never Modo Camuflagem / Modo Cloak / Cloak Mode)
Quick Launch = Início rápido
Always On = Sempre ativo
Smart Proxies = Proxies inteligentes (the feature page's own title)

TERMS — the docs' technical words: one rendering per concept, in every string.
reverse proxy = proxy reverso
farm / server farm = o farm / o farm de servidores (masculine; never cluster, never fazenda)
access key = chave de acesso · certificate = certificado · container = contêiner · firewall = firewall
standalone = independente (never autônomo, never avulso) · managed = gerenciado · web panel = painel web
server profile = perfil de servidor (plural perfis de servidor)

PROSE — preferred wording in running text; a preference, not a ban.
feature(s) = recursos · download (verb) = baixar
open source = código aberto (not "open source")
app = aplicativo · plan = plano/planos · reseller = revendedor

KEYWORDS — meta_title and meta_description keys ONLY (Play listing research and Search
Console, Oct 2026). Brazilians search "VPN grátis", "VPN grátis sem cadastro", "sem limite de
dados", "baixar VPN grátis" and "VPN de código aberto". In those two keys: Free VPN = VPN
grátis, no registration / no sign-up / no account = sem cadastro, unlimited data = sem limite
de dados.
