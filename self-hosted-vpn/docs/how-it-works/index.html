Checked on 2026-10-22 against the VpnHood repo's develop (SERVER v9.0.859; the CLIENT's v8.1.841 tag for what differs): TCP goes as packets by default (the server's TUN adapter and NAT), and one request per connection only in Cloak Mode, on a proxy-only server (Docker) or with split by domain (ClientSession.CalcUseTcpProxy); every byte is inside TLS or QUIC, UDP datagrams are AES-GCM (StreamHeadCryptor went in 2023); framing is WebSocket over TLS; the certificate passes by CA chain for the key's host name or by the key's pinned hash (ConnectorService); DNS is forced into the tunnel by default (SplitDnsMode.IncludeAll); the server refuses its own and local addresses (NetFilter); anything that is not a VpnHood request gets HTTP 401.
