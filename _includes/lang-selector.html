{% comment %} Language selector. Renders nothing until a second language exists — languages are discovered from site.data.i18n (a folder per language, generated by vhtranslator), display names come from _data/languages.yml. Each entry links to the current page's counterpart in that language when it exists, else to that language's home page. Explicit choices are persisted by /assets/js/lang.js via data-vh-lang. One Bootstrap dropdown serves both the desktop header and the mobile off-canvas.
