{%- comment -%} Shared FAQ section. Renders the visible Bootstrap accordion AND the FAQPage JSON-LD from one source: the language's FAQ strings in _data/i18n//faqs.json (numbered keys q1/a1, q2/a2, ... plus the section chrome: eyebrow/heading/desc/view_all). Falls back to English while a language's file has not been generated yet. Answers may contain inline HTML — Google permits a/b/strong/em/br/ul/ol/li in FAQ answers. Internal links inside answers are rewritten onto the page's language tree via vh_base. Parameters: heading — render the section heading + wrapper (default: true). Pass heading=false to emit just the accordion (e.g. the /faq page, which supplies its own page heading). explore — show the "View All FAQs" link to /faq (default: true). Pass explore=false on the /faq page itself. wrapper_class — class on the section wrapper, used to control the FAQ's vertical spacing per page (default: 'section-space', i.e. 200px top + bottom). Footer-adjacent pages pass 'section-space-top' to drop the big bottom gap; pages with another section after the FAQ (e.g. home) keep the default. eyebrow — eyebrow label above the heading (default: the file's `eyebrow`). schema — emit the FAQPage JSON-LD (default: true). {%- endcomment -%} {%- assign vh_faq_lang = page.lang | default: 'en' -%} {%- assign vh_faqs = site.data.i18n[vh_faq_lang].faqs | default: site.data.i18n.en.faqs -%} {%- capture vh_href_lang %}href="{{ vh_base }}/{% endcapture -%} {%- comment -%} Questions nest under the section title (h2) on content pages, or under the page's own h1 on /faq (heading=false). {%- endcomment -%} {%- if include.heading == false -%}{%- assign q_level = 'h2' -%}{%- else -%}{%- assign q_level = 'h3' -%}{%- endif -%} {%- capture faq_accordion -%}
