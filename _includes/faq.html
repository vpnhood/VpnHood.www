{%- comment -%} Shared FAQ section. Renders the visible Bootstrap accordion AND the FAQPage JSON-LD from one source: the language's FAQ strings in _data/i18n//faqs.json, selected and ordered by _data/faq_sets.yml. Questions are keyed by name, not position: `is_open_source` reads `q_is_open_source` / `a_is_open_source`. Each key falls back to English on its own, so a question added here shows in every language immediately instead of rendering blank until vhtranslator catches up. Answers may contain inline HTML - Google permits a/b/strong/em/br/ul/ol/li in FAQ answers. An answer prints through _includes/faq-answer.html, which moves its internal links onto the page's language tree and unwraps a link to the page being rendered. Keep a question out of the set of the page its answer links to all the same, or the page carries a short version of itself. Parameters: set - name of a list under `sets:` in _data/faq_sets.yml, e.g. set="go_premium". Defaults to the full `all` list (used by /faq). An unknown name falls back to `all` rather than rendering nothing. keys - comma-separated base names, for a one-off selection that does not deserve an entry in faq_sets.yml. Wins over `set`. heading - render the section heading + wrapper (default: true). Pass heading=false to emit just the accordion (e.g. the /faq page, which supplies its own page heading). explore - show the "View All FAQs" link to /faq (default: true). Pass explore=false on the /faq page itself. wrapper_class - class on the section wrapper, used to control the FAQ's vertical spacing per page (default: 'section-space', i.e. 200px top + bottom). Footer-adjacent pages pass 'section-space-top' to drop the big bottom gap; pages with another section after the FAQ (e.g. home) keep the default. eyebrow - eyebrow label above the heading (default: the file's `eyebrow`). schema - emit the FAQPage JSON-LD (default: true). Only /faq passes it through; every other page passes schema=false, because eight pages each declaring a different FAQPage entity is duplication for no gain - Google restricted FAQ rich results to government and health sites in 2023, so the markup is inert either way. {%- endcomment -%} {%- assign vh_faq_lang = page.lang | default: 'en' -%} {%- assign vh_faqs_en = site.data.i18n.en.faqs -%} {%- assign vh_faqs = site.data.i18n[vh_faq_lang].faqs | default: vh_faqs_en -%} {%- comment -%} Selection: explicit keys, then a named set, then everything. {%- endcomment -%} {%- if include.keys -%} {%- assign vh_faq_list = include.keys | split: ',' -%} {%- else -%} {%- assign vh_faq_list = site.data.faq_sets.sets[include.set] | default: site.data.faq_sets.all -%} {%- endif -%} {%- comment -%} Questions nest under the section title (h2) on content pages, or under the page's own h1 on /faq (heading=false). {%- endcomment -%} {%- if include.heading == false -%}{%- assign q_level = 'h2' -%}{%- else -%}{%- assign q_level = 'h3' -%}{%- endif -%} {%- capture faq_accordion -%}
