Two rewrites, both of them about links: 1. an internal link is moved onto the page's own language tree, so href="/free-vpn/go-premium/" becomes href="/fa/free-vpn/go-premium/" on a Persian page, except a link to /legal/, whose pages are English only, as the footer's links to them are; 2. a link to the page currently being rendered is unwrapped to plain text, because a link to the page you are already on is a dead end. Rule 2 is a safety net, not a licence: an answer that links to a page is usually a short version of what that page says at length, so listing it in that page's own set in _data/faq_sets.yml repeats the page inside itself. Keep it out of the set; see the note there. An answer may hold several links, but at most ONE to any page: the unwrap removes that link's opening tag and the first after it, and leaves the rest of the answer, other links included, as it is. tools/check-self-links.py enforces that invariant.
