Two rewrites, both of them about links: 1. an internal link is moved onto the page's own language tree, so href="/free-vpn/go-premium/" becomes href="/fa/free-vpn/go-premium/" on a Persian page; 2. a link to the page currently being rendered is unwrapped to plain text, because a link to the page you are already on is a dead end. Rule 2 is a safety net, not a licence: an answer that links to a page is usually a short version of what that page says at length, so listing it in that page's own set in _data/faq_sets.yml repeats the page inside itself. Keep it out of the set; see the note there. Assumes at most ONE per answer, which is what lets the unwrap find the matching by taking the first one after the opening tag. tools/check-self-links.py enforces that invariant.
