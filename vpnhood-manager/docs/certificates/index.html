Written for the MANAGER of 2026-10-19 (access server v4.0.414, origin/development; the console's develop) and read from both sources: Add creates a self-signed certificate, Public and Manual, and binds it to the server it was added from; Upload takes a PFX with an exportable key, defaults to Private in the console, and is always farm-wide; a new certificate for a domain the farm has replaces the old one and keeps its visibility if higher; every non-DomainOnly certificate goes to its servers whatever its visibility, and a server picks one by SNI; the token carries the PublicInToken certificate's name and hash, with IsValidHostName from its CA signature; a self-signed token certificate needs a PublicInToken address; Push token to clients sends keys only while a farm server has a PublicInToken address; Priority only orders redirect domains; AutoSign uses Let's Encrypt over HTTP-01 on port 80 through any farm server, MANAGER checks the token first, renews 30 days before expiry on a daily job, and falls back to Manual after six failures in a row. Its screenshots are the MANAGER docs test farm as it is (Vh/.user/docs/ manager-test-projects.md), in MANAGER's dark theme.
