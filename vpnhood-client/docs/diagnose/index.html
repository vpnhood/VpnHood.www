Checked against the Avalonia UI of v9.1.868, not the wiki, which is out of date: its Send Report and reference number are gone, and the SPA is only a sample. Diagnose is in the menu and on some error messages, connected or not; Stop Diagnosing ends it; the message that follows offers Open Report, which opens the log inside the app, scrolled to its end. A button at the top of that page shares it as a file on a phone or tablet, copies it on a computer and downloads it in a browser on Remote Access, which is plain http and so has no clipboard or share of its own; a version from before that button, and a TV's own screen, have none, so the step keeps the screenshot. The bold words are each language's app labels, from VpnHood.AppUi.Assets.Classic: DIAGNOSE, STOP_DIAGNOSING and OPEN_REPORT. What the report holds comes from the code: the version, the OS, the settings as JSON and, while diagnosing, the country, then the connection at the Information level. The app sends none of it. Addresses go through the redactor, which is on by default, but the settings do not, so a custom DNS server shows as it is: the page says so. Sites are logged only at the Debug level. The pictures are the app's own in the reader's language, cut to the part each step needs, which also drops the sample data's old version number: tools/make-app-shots.py draws them. {%- endcomment -%} {% capture vh_article %} {% include docs-hero.html art="vpnhood-client/docs/hero-diagnose.svg" %}
