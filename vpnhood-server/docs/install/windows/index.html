Every command here ran in Windows Sandbox (Windows 11, PowerShell 5.1) and on a clean Windows Server 2025 VM, against VpnHood! SERVER v9.1.866, whose install script is pub/lib/vh-installer/win/ in the VpnHood repo. On the VM a Linux client connected through the real adapter with no Hyper-V role, and could not connect until the firewall rule was added; the uninstaller deletes itself, so -purge goes in its place, not after it. A client edition of Windows runs no script by default, so vhserver.ps1 goes through -ExecutionPolicy Bypass: the wiki's ./vhserver.ps1 gen fails there. The installer does not touch Windows Firewall, and it says so, so the rule is a step here. The server's task repeats every minute, so stopping it disables the task first, as the installer does. A managed server is added from MANAGER, whose steps live in its own docs: the MANAGER promo right before the standalone steps links to /vpnhood-manager/docs/add-server/. This page is a quick start, like install/linux/: press Enter at the installer's questions.
