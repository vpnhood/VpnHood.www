Every step and limit was run on 2026-11-24 as a plain user in WSL's Ubuntu, with v9.1.872 from VpnHood.App.Server's latest release: the package holds one folder, the version; port 443 is refused (Permission denied) and the server goes on without it; 8443 works; the TUN device cannot be made, so apps use TCP forwarding, Cloak Mode; the OS settings fail; gen puts the port in the key; stop ends it; nohup's server outlives the shell that started it. .NET's Ping, which the server forwards ICMP with, works for a plain user (ping_group_range, or the ping command), so the wiki's "no ping" is gone. The storage is the working folder's (ServerApp: no publish.json two folders up), hence one folder for every command. QUIC is off unless set, so MsQuic, which only root installs, is not a limit here. No MANAGER promo: MANAGER installs its servers with root. The install command needs root, said plainly, with no promise of an installer without it.
