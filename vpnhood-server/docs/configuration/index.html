Each row's id is the wiki's anchor for it, the setting's name in lower case, so a link to a wiki section finds its row here. Checked on 2026-11-23 against develop (VpnHood 4b388b4b9): AppSettings and ServerApp (the file, VH_APPSETTINGS, the tracker), ServerConfig, FileAccessManagerOptions and FileAccessManager (the UDP port it keeps, QUIC's port 0, the location lookup), SessionOptions, TrackingOptions, NetFilterOptions, OsOptions and NLog.config (the track and session logs). ServerConfig is laid over FileAccessManager's settings, and over a managed server's server profile (VpnHoodServer.Configure), which is why it wins. Left out on purpose: what an access manager sets and a person never does (ConfigCode, Certificates, ServerSecret, EnableHttp01Challenge, UpdateStatusInterval); ManagementSecret, which the Docker installer writes and nothing reads; DownloadsPath, which no app uses; and StartPadding, experimental and off, which the site does not name (owner, 2026-11-05, on the VPN detection page). Linux and Docker only, as the other server pages. Code inside a sentence is a placeholder from _data/code.yml, filled in by copy.html; the setting names and defaults in the tables are markup. {%- endcomment -%} {% capture vh_article %} {% include docs-hero.html art="vpnhood-server/docs/hero-configuration.svg" %}
