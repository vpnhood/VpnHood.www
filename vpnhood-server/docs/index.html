Install VpnHood! SERVER on Linux

One command installs the server, runs it as a service and starts it. A second one prints the access key you give to your users.

Before you start

  • A Linux machine, x64 or arm64, with a public IP address.
  • Root access. Without it, follow the rootless install instead.
  • The ports your server listens on, open in its firewall.

Install

Run this as root. It downloads the latest release into /opt/VpnHoodServer and starts it as a service.

sudo su -c "bash <( wget -qO- https://github.com/vpnhood/VpnHood.App.Server/releases/latest/download/VpnHoodServer-linux.sh)"

The installer uses wget. If your system doesn't have it, install it with your distribution's package manager first.

Get your first access key

Generate a key, then paste it into VpnHood! CLIENT on any device to connect through your server.

sudo /opt/VpnHoodServer/vhserver gen

Treat an access key like a password: anyone who has it can connect through your server.

Everyday commands

CommandWhat it does
sudo /opt/VpnHoodServer/vhserver genPrints a new access key.
sudo /opt/VpnHoodServer/vhserver stopStops the server.
sudo /opt/VpnHoodServer/vhserver startStarts it again.
